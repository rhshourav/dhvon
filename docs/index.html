    Engine

    If it exists, it plays.

    Media3 with FFmpeg extensions. Pick how it decodes, per file and per moment. If nothing can decode a file, VLC steps in.

    Hardware decoding through MediaCodec: the coolest, longest-lasting way to play.

    Auto-rescue
    Media3VLC

    Plays in Media3 with hardware decoding. VLC never wakes up.

    VLC steps in only when no decoder exists at all. Seek, double-tap, speed, pinch-zoom and Picture-in-Picture keep working, and a VLC badge shows in the top bar. VLC plays its own audio, so the equalizer is bypassed, and embedded subtitles aren’t shown (external .srt, .ass and .vtt still load).

    Built on AndroidX Media3, FFmpeg and libVLC.

    Nothing is decoration

    Every choice has a reason.

    Obsidian #08090D

    OLED pixels at near-zero light. Less battery, deeper contrast, and the video is always the brightest thing.

    Silver, then purple

    Silver is the logo’s metal. Purple only ever means “active”: the seekbar, the selected tab, this page’s top line.

    System font

    No font download, no layout shift. SF Pro on Apple devices, Roboto on Android.

    One easing curve

    Everything decelerates like a physical object, so motion feels caused, not played.

    Transform and opacity

    The only properties the GPU animates without re-layout. That’s how it holds 60 fps.

    Reduced motion

    If your OS asks for calm, every animation here yields.
